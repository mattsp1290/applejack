# Research

These five files were produced on 2026-10-27. They are public-source research notes that informed the macOS Windows Steam runner plan. `import.sh` copies them from `APPLEJACK_RESEARCH_SOURCE_DIR` and prints the SHA-256 of each copy.

| File | Covers |
| --- | --- |
| `Windows games on Android and macOS.md` | The report. How Android's Windows game stack maps onto Apple Silicon. |
| `android_stack.md` | The software stack for running x86 and x86-64 Windows Steam games on Android handhelds as of October 2026. |
| `cpu_translation.md` | x86-64 to ARM64 CPU translation layers for Windows games on Android, Linux, and Apple Silicon macOS. |
| `macos_build_gaps.md` | What an open-source Winlator or GameHub style Steam runner for Apple Silicon would need. |
| `macos_state.md` | The state of running Windows x86-64 DirectX Steam games on Apple Silicon macOS as of October 2026. |
