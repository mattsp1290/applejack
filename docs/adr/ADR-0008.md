# ADR-0008: Native ARM64 engine is a gated track, not a blocker

## Status

Accepted, 2026-10-28

## Context

The user's paid account may qualify for the cross-architecture entitlement. Apple's documentation and provisioning behavior for individual accounts are unverified.

## Decision

The native ARM64 engine is a gated track, not a blocker. Work proceeds only after its three gates are green. N1 is an upstream or vendored ARM64 Wine that builds on the host. N2 is the cross-architecture entitlement granted to the project's account and exercised by a signed helper bundle for a parent and a child process. N3 is a reproducible build of the Darwin FEX DLLs that load in that Wine.

## Consequences

The rest of the plan does not wait on the native engine. If Apple does not provision the entitlement on an individual account, only the native track is affected.
