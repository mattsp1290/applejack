# ADR-0004: D3DMetal is user-supplied, never downloaded or bundled

## Status

Accepted, 2026-10-28

## Context

The Gcenx cask contains D3DMetal, which is one reason it cannot be republished. Apple's GPTK disk image carries the D3DMetal payload. The user can mount that image.

## Decision

The launcher detects an Apple GPTK disk image the user has mounted. On request it copies the D3DMetal payload into a per-user overlay of the installed engine and records that the user accepted Apple's license. The backend is offered only after assumption A5 is verified. A5 states that D3DMetal loads with the project's Wine build. If A5 is refuted, the D3DMetal backend is removed from the Rosetta engine and recorded as unavailable.

## Consequences

D3DMetal lives only in the per-user overlay `engines/<id>/<version>.user/`. Engine bundles never contain it.

Rejected alternatives.

- Shipping D3DMetal.
