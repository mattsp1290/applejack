# ADR-0006: Client-required titles launch through the real Windows Steam client

## Status

Accepted, 2026-10-28

## Context

Some titles need a Steam client to run. The real Windows Steam client is proven under Rosetta and CrossOver. One client install and one interactive login preserves the one-click outcome.

## Decision

Titles that need a Steam client launch through the real Windows Steam client in one shared client prefix. The launcher writes `appmanifest_<appid>.acf` and places depot files under a shared library mapped into the prefix so the client adopts the install. It then runs `steam.exe -applaunch <appid>`. Per-title isolated client prefixes are opt-in. `drm = unknown` takes the client path.

## Consequences

The design relies on assumption A2, that the client adopts a pre-populated install and performs only a verification pass. The real Windows Steam client may break on a Valve update. The headless shim is a spike, not a deliverable.
