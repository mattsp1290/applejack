# ADR-0007: Synchronization mode comes from the bundle

## Status

Accepted, 2026-10-28

## Context

Wine builds differ in the sync modes they support. msync depends on a patch set applying cleanly to the chosen Wine tag.

## Decision

`BUNDLE.toml` advertises the sync modes the Wine build supports, from `msync`, `esync`, and `none`. The engine defaults to the first advertised mode. Work package 3 gates msync on the patch set applying cleanly to the chosen Wine tag. If it does not, the first bundle advertises esync only.

## Consequences

The launcher reads the sync mode from the bundle and does not assume one.

Rejected alternatives.

- Hard-coding `WINEMSYNC=1`.
