# ADR-0001: Engine-agnostic core with a versioned engine interface

## Status

Accepted, 2026-10-28

## Context

The research report's central finding is that the engine will be replaced within about eighteen months. The Steam layer and the config database persist across that change. Rosetta removal in macOS 28 makes the first engine end-of-life around fall 2027.

## Decision

`applejack-engine` defines an `Engine` trait with `install`, `doctor`, `create_prefix`, `apply_overrides`, `launch`, and `capabilities` operations. `Engine` is a conceptual name. Each engine bundle has an on-disk layout described by a `BUNDLE.toml` inside the bundle. `rosetta-wine` is the first implementation. `native-arm64` is the second.

## Consequences

The core, the Steam layer, and the config database depend on the engine interface and not on a specific engine. Engines can be swapped and versioned without changing the launcher.

Rejected alternatives.

- A Rosetta-only launcher. It dies with macOS 28.
- A native-only launcher. It is blocked on externals today.
