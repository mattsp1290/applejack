# ADR-0009: Rollback is a first-class engine and prefix operation

## Status

Accepted, 2026-10-28

## Context

One bad engine release must not strand every prefix. The real Windows Steam client may also break on a Valve update.

## Decision

The launcher keeps the previous engine version installed. It snapshots a prefix with an APFS clone before any engine-version change or Steam client update. It offers `prefix reset`.

## Consequences

The launcher stores the previous engine version and prefix snapshots under `prefixes/.snapshots/`. Every engine-version change and Steam client update takes a snapshot first.
